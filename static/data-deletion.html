User Data Deletion

Last updated: 5 August 2026

Taxova.ai stores WhatsApp-related account data and invoice files you send to the service. You can request deletion as follows.

How to request deletion

  1. Email adityaraj6112025@gmail.com
  2. Subject: Taxova.ai data deletion request
  3. Include the WhatsApp phone number used with Taxova.ai (with country code)

What we delete

  • Client profile linked to that phone number
  • Stored invoice files and extracted invoice records for that client
  • Related dashboard / chat history we hold for that client, where technically feasible

Timing

We aim to complete deletion within 30 days of verifying your request, unless we must retain data longer for legal or accounting obligations.
